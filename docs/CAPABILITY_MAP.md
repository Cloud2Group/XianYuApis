# XianYuApis 能力地图

- 层级：L1
- 状态：Draft
- 更新时间：2026-07-28

## 文档职责

本文件列出闲鱼卖家运营能力基座的目标范围、实现顺序和当前证据状态。优先级表示建设顺序，不代表长期范围排除。

## 状态标签

| 标签 | 含义 |
| --- | --- |
| 目标 | 已进入产品范围，尚未开始验证 |
| 静态发现 | App 中存在类、方法或 API 名称，参数和结果待动态确认 |
| Web 参考 | 历史 Web/Cookie 代码存在对应实现，只用于研究和字段对照，不进入生产执行 |
| POC | 本地协议、模拟器或桥已跑通，尚未接入真实闲鱼结果 |
| 动态待验证 | 已有明确入口，等待真实账号回调和结果确认 |
| API 就绪 | Query、Command、Event、错误和验收均已完成 |

## P0：公共执行与账号运行时

### 公共执行

Capability Registry 对内部调用者提供按账号的能力发现结果，说明当前 App 版本、Worker 类型、验证级别和不可用原因。

Query：

- 查询能力注册表；
- 查询 Operation 状态和结果；
- 查询 Event 和审计记录。

Command：

- 重试或取消允许中止的 Operation；
- 管理事件订阅游标。

Event：

- Operation 状态变化；
- Runtime 状态变化；
- 系统告警和验证请求。

当前状态：领域语义已确认，标准 API 尚待设计。

### 账号与 Session

Query：

- 查询账号托管状态、登录状态和 Runtime 状态；
- 查询最后心跳、同步进度和需要处理的验证。

Command：

- 开始登录授权；
- 暂停、恢复和结束托管；
- 触发重新登录或状态同步。

Event：

- 登录成功、失效和重新授权；
- Runtime 连接、断线和恢复；
- 进入或退出人工操作模式。

当前状态：账号生命周期与 Runtime 状态已拆分并形成 v1 契约，见 `docs/api/SESSION_RUNTIME_V1.md`；真实登录恢复待验证。

## P0：会话与消息

第一版只验收文字消息闭环，schema 通过 `content_type` 预留图片、商品卡片、语音和文件扩展。

Query：

- 查询会话列表、会话详情、消息历史和未读状态；
- 按卖家账号、买家和主商品定位唯一会话。

Command：

- 创建或取得会话；
- 发送文字、回复消息、标记已读；
- 后续扩展图片、商品卡片、语音、文件和其他消息类型。

Event：

- 收到消息；
- 消息发送结果；
- 未读状态和会话状态变化；
- 传输连接状态变化。

当前状态：Native bridge 为 POC；AIM 收发入口已静态确认，真实回调待验证。历史 Web 代码只用于字段和行为对照。

## P1：平台素材与媒体

Query：

- 查询平台素材和账号级闲鱼媒体实例；
- 查询上传、失效和复用状态。

Command：

- 上传图片、视频、音频或文件；
- 为目标账号生成媒体实例；
- 失效后重新上传。

Event：

- 上传成功、失败和资源失效。

当前状态：App 原生媒体路径待研究；历史 Web 上传代码只作为字段参考。

## P1：商品

Query：

- 查询平台商品模板；
- 查询账号商品列表、详情、价格、上下架状态和运营数据。

Command：

- 发布、编辑、改价、擦亮、上架和下架；
- 从模板发布到指定账号；
- 把模板变化同步到指定闲鱼商品。

Event：

- 发布和审核结果；
- 商品状态、价格和平台处理结果变化。

当前状态：App 中已静态发现发布、编辑、下架等 MTop 名称，动态参数待确认。历史 Web 商品代码只作为字段参考。

## P2：订单与履约

第一版先做订单 Query、状态 Event 和已确认的发货/物流 Command；退款、取消和售后先以查询与事件为主。

Query：

- 查询订单列表、详情、状态、支付和物流信息；
- 按会话、商品、买家和卖家账号检索订单。

Command：

- 发货、填写或更新物流；
- 处理支持的退款、取消和其他履约动作。

Event：

- 下单、付款、取消、发货、确认收货、退款和交易完成。

当前状态：App 中已静态发现发货和物流相关 MTop 名称；完整订单状态和操作参数待研究。

## P3：商品评论与交易评价

第一版先做 Query 和 Event；回复、删除、隐藏等写能力逐项经过 App 原生动态确认后注册。

Query：

- 查询商品评论；
- 查询订单对应的买家评价和卖家评价。

Command：

- 回复或管理平台允许操作的商品评论；
- 提交或管理平台允许操作的交易评价。

Event：

- 新商品评论；
- 新交易评价和后续评价状态变化。

当前状态：目标范围已确认，具体 App 能力和权限待研究。

## 横切能力：同步与恢复

Query：

- 查询各业务域初始同步和增量同步进度；
- 查询游标、缺口和最后成功时间。

Command：

- 启动初始同步；
- 补齐指定时间段或游标缺口；
- 重新校准闲鱼状态与本地副本。

Event：

- 同步进度、完成、失败和数据缺口。

当前状态：三域独立 `SyncJob`、游标、缺口和重试契约已确认，详见 `docs/api/SYNC_V1.md`；实现和真实 App 参数仍待验证。

## 第一条实现主线

```text
账号 Runtime 状态
→ 会话和消息 Query
→ message.received Event
→ message.send Command
→ Operation 最终结果
→ 本地账本与断线补偿
```

完成这条主线后，再按媒体、商品、订单、评论和评价的依赖顺序扩展。
