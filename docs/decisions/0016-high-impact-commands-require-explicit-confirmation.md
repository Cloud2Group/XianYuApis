# ADR-0016：高影响 Command 需要明确确认和目标版本

- 状态：Accepted
- 日期：2026-07-28

## 背景

改价、发货、删除商品、退出登录和结束托管等操作的影响不同。若所有 Command 使用相同提交方式，旧页面、重复请求或错误目标可能产生高成本结果。

## 决策

Capability Registry 为能力声明 `normal`、`sensitive` 或 `destructive` 执行等级。高影响 Command 按能力要求携带明确确认、目标对象当前版本和操作原因，并使用更严格的权限与审计规则。该等级只负责执行安全，不判断业务上是否应该执行。

## 结果

- API schema 可以对高影响能力实施一致保护。
- 对象版本变化时返回冲突结果，由调用者重新查询后决定。
- 审计记录可以区分普通、敏感和破坏性操作。
