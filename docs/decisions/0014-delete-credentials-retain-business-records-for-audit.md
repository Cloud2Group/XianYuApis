# ADR-0014：结束托管立即清除凭证，业务记录按周期保留

- 状态：Accepted
- 日期：2026-07-28

## 背景

账号结束托管后，平台继续持有登录票据和设备私密状态没有运行价值；但立即删除全部订单、操作和结算记录又会让收益核对、问题追踪和审计失去依据。

## 决策

结束托管时立即清除登录票据、Device Profile 私密内容、App 密钥、连接状态和 Worker 缓存。商品、订单、收益、操作和错误记录按结算与审计周期保留，周期结束后删除或匿名化。账号主可以导出与自己账号相关的数据，所有数据生命周期操作进入审计账本。

## 结果

- Session Vault 与业务账本采用不同删除策略。
- 数据模型需要记录保留期限和删除状态。
- 账号重新合作时按新托管关系重新授权，不复用已清除凭证。
