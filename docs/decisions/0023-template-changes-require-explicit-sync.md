# ADR-0023：商品模板变更通过显式 Command 同步

- 状态：Accepted
- 日期：2026-07-28

## 背景

一个平台商品模板可能生成多个账号上的闲鱼商品。模板内容直接自动覆盖在售商品，会让一次编辑跨账号产生不可预期的改价、文案或上下架变化。

## 决策

模板编辑只改变模板本身。向闲鱼商品传播必须通过显式 `item.template.sync` Command，指定目标账号和商品，可先生成变更预览；每个目标商品独立执行、确认和记录结果。

## 结果

- 模板和闲鱼商品状态分离。
- 上层 AI 或批量策略决定何时同步。
- 单个账号或商品失败时，其余目标可以独立完成。
