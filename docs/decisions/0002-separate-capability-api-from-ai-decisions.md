# ADR-0002：闲鱼能力 API 与 AI/业务决策分层

- 状态：Accepted
- 日期：2026-07-28

## 背景

项目既计划提供闲鱼原生能力 API，也计划在未来接入 AI Agent、自动砍价、多账号策略和人工接管。如果把能力执行与业务判断放进同一层，底层接口会被具体商业模式和 AI 实现绑定，难以独立测试、复用和长期稳定。

## 决策

系统采用四层边界：

1. 闲鱼功能实现：对接 App 原生、Web 回退或其他具体执行路径。
2. 标准闲鱼 API：接收目标账号和操作参数，可靠执行并返回结构化结果。
3. 调用适配：把 API 提供给普通程序、第三方软件或 AI 工具。
4. 业务决策与编排：决定回复内容、价格策略、执行时机、多账号策略和人工接管。

标准 API 可以处理鉴权、参数校验、账号状态、幂等、队列、超时、执行级重试、结果确认、日志和审计，但不包含业务判断。

## 结果

- 第一阶段只建设完整、稳定、可独立调用的闲鱼能力 API 基座。
- AI 是未来的 API 调用者，不是底层能力的一部分。
- 商业模式和自动化策略可以替换，底层能力契约保持稳定。
