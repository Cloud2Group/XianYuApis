# ADR-0003：逻辑账号运行时与物理设备解耦

- 状态：Accepted
- 日期：2026-07-28

## 背景

项目的长期目标是集中管理大量闲鱼账号。如果账号与手机或其他物理设备永久一一绑定，硬件成本、故障迁移和规模化调度都会直接受设备数量限制。

## 决策

每个闲鱼账号建模为独立的逻辑 `Account Runtime`，包含登录态、设备身份、消息连接、操作队列和账号运行状态。逻辑 Runtime 与物理设备不要求一一对应；未来可以由共享机器、Worker 或设备池承载多个 Runtime。

## 结果

- 第一阶段仍以单账号验证为主。
- Runtime 必须保持账号级状态、凭证、队列和日志隔离。
- 具体承载形态可以随研究结果变化，不影响上层标准 API。
