# ADR-0017：Query 本地优先，按需实时刷新

- 状态：Accepted
- 日期：2026-07-28

## 背景

所有查询都实时访问 App 会增加延迟和连接压力；只读取本地副本又会让调用者误解数据新鲜度。不同场景对速度和一致性的要求不同。

## 决策

Query 默认读取本地标准化状态，并在响应中返回数据来源、最后观察时间、同步游标和完整性状态。调用者可以使用 `consistency: fresh` 要求通过 App Native Worker 刷新。高影响 Command 在执行前执行必要的最新状态和版本校验。

## 结果

- 普通列表和历史查询保持低延迟。
- 需要最新状态的调用可以显式承担刷新成本。
- 调用者始终能判断返回数据是否为本地观察值或刚刚从闲鱼刷新。
