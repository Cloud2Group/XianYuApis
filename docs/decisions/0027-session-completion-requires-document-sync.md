# ADR-0027：会话完成必须同步项目文档

- 状态：Accepted
- 日期：2026-07-28

## 背景

项目会在同一工作目录中使用多个短会话推进。若结论只留在聊天记录里，后续会话会重复询问、误读临时推测，或丢失验证结果。

## 决策

每个会话结束前，必须把新决策、技术事实、研究结果、改动文件、验证结果和下一步同步到项目文档：

- 专题内容进入对应 L0-L4、研究或 API 文档；
- 难以逆转的取舍进入 ADR；
- 当前状态和接手入口进入 `CONTEXT.md`；
- 新文件进入 `PROJECT_MAP.md`；
- 协作方式和入口规则集中记录在 `WORKING_AGREEMENT.md` 与 `DOCUMENTATION_GOVERNANCE.md`。

聊天内容只承担过程沟通，项目文档承担跨会话事实来源。

## 结果

- 新会话可以从固定入口线性接手；
- 用户确认一次的决策可以在后续会话持续生效；
- 技术事实、推测和产品取舍保持可区分；
- 每个阶段都有明确的完成标准、验证记录和下一步。
