# ADR-0005：统一买家身份，业务数据保持账号归属

- 状态：Accepted
- 日期：2026-07-28

## 背景

同一个闲鱼买家可能同时咨询或购买多个托管账号的商品。完全按卖家账号拆开买家身份会丢失平台级关系；直接混合所有会话和订单又会破坏合作账号之间的数据边界。

## 决策

系统内部按闲鱼用户 UID 识别统一的买家身份。会话、消息、订单和评价仍保留具体卖家账号归属。平台可以在权限允许时形成跨账号买家视图，合作账号主只查看与自己账号相关的数据。

## 结果

- 买家身份与账号内业务记录分开建模。
- 所有会话和交易记录必须携带卖家 `account_id`。
- 跨账号查询属于平台能力，不改变原始数据归属。
