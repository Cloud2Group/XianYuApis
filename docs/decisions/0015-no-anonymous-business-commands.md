# ADR-0015：所有业务 Command 必须关联调用者身份

- 状态：Accepted
- 日期：2026-07-28

## 背景

即使第一阶段 API 只在本机或内网使用，内部人员、脚本、系统任务和未来 AI 都可能对同一账号执行操作。如果只记录“账号做了什么”而没有记录“谁发起”，后续审计和问题定位会失去关键链路。

## 决策

每个业务 Command 必须关联 `actor_id` 和 `actor_type`。第一阶段权限模型可以保持简单，但不接受匿名业务操作。Operation 账本记录调用者、目标账号、Capability、参数摘要、执行结果和实际 Worker；敏感参数进行脱敏。

## 结果

- 内部脚本和系统任务也需要稳定身份。
- 未来接入 AI 或第三方应用时沿用同一 Actor 模型。
- 查询和审计可以按调用者、账号和能力追踪完整操作链。
