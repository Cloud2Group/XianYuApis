# ADR-0006：接收命令不代表闲鱼操作成功

- 状态：Accepted
- 日期：2026-07-28

## 背景

闲鱼操作可能经过本地排队、App 调用、网络请求、平台确认和状态落库多个阶段。如果 API 在命令进入队列时直接返回成功，调用者会把“准备执行”误认为“闲鱼已经完成操作”。

## 决策

标准 API 区分 Command 接收和 Operation 结果。API 可以先返回 `accepted` 与 `operation_id`；只有闲鱼成功回调或系统观察到目标状态已经生效时，Operation 才标记为 `succeeded`。

## 结果

- 调用者可以通过查询或事件等待最终结果。
- 超时、失败、需要登录和需要验证拥有独立状态。
- 所有写操作都保留从接收命令到最终结果的完整执行记录。
