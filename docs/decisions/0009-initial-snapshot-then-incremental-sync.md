# ADR-0009：账号首次接入先建快照，随后增量同步

- 状态：Accepted
- 日期：2026-07-28

## 背景

只从托管当天记录数据会丢失已有商品、历史会话和近期订单上下文；每次全量同步又会造成重复请求和较长等待。

## 决策

账号首次接入时，尽量导入闲鱼当前可访问的商品、会话、消息、订单和评价历史，建立初始业务快照。之后为各业务域保存独立游标，只同步新增和变化数据。历史范围支持按全部、时间窗口或托管起点配置，大数据量可以后台分批补齐。

## 结果

- 新账号接入后可以保留已有业务上下文。
- 实时运行使用增量同步，断线时按游标补偿缺口。
- 系统需要记录每个业务域的同步进度和完整性。
