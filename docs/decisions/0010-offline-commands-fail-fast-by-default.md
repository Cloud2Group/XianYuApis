# ADR-0010：账号离线时 Command 默认快速返回异常

- 状态：Accepted
- 日期：2026-07-28

## 背景

账号掉线、登录失效或 App 不可用时，如果 Command 被静默无限排队，调用者无法判断操作是否还会执行，恢复后还可能在错误时间发送消息或修改商品。

## 决策

目标 Account Runtime 不可用时，Command 默认返回 `runtime_unavailable` 或 `needs_login`。调用者可以对适合延迟执行的能力显式设置 `wait_until_online` 和截止时间；消息发送等时效操作默认快速失败。等待超时必须进入明确终态。

## 结果

- 调用者始终知道任务是否正在等待。
- 恢复后不会突然执行已经失去时效的默认任务。
- 上层编排系统可以按业务需要决定重试或延迟执行。
