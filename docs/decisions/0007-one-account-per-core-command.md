# ADR-0007：底层 Command 每次只操作一个账号

- 状态：Accepted
- 日期：2026-07-28

## 背景

未来需要支持对大量账号批量改价、上架和发送消息。如果底层 API 直接接收多个账号，一个账号的登录失效、超时或平台失败会让整批任务的结果、重试和审计变得模糊。

## 决策

每个核心 Command 只包含一个 `account_id`，并产生一个独立 Operation。多账号批量任务由上层控制系统拆分为多个单账号 Command，再汇总结果。

## 结果

- 每个账号可以独立成功、失败、重试和审计。
- 底层能力 API 不包含多账号运营策略。
- 上层可以按需要实现批量、并发、限速和部分成功语义。
