# ADR-0022：会话内有序、Event 至少一次投递

- 状态：Accepted
- 日期：2026-07-28

## 背景

买家消息和回复依赖同一会话顺序；不同账号和会话之间没有必要为了全局排序增加等待。网络断线和重连又要求事件可以重放，避免一次推送失败造成数据缺口。

## 决策

同一 `conversation_id` 内按平台观察顺序维护事件顺序；不同会话之间不保证全局顺序。Event 采用至少一次投递，调用者按 `event_id` 去重，消息按 `message_id` 去重，并通过游标和补偿查询修复乱序或缺口。

## 结果

- 会话内的业务处理可以依赖顺序。
- 跨账号和跨会话可以并行。
- Event 消费者必须幂等。
