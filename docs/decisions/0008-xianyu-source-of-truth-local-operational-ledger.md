# ADR-0008：闲鱼是真实状态来源，本地保存标准化业务账本

- 状态：Accepted
- 日期：2026-07-28

## 背景

如果标准 API 只临时转发请求，系统重启后会丢失消息上下文、操作结果和状态变化，也难以完成补偿、审计和多账号运营。反过来，如果只相信本地预期状态，又可能把排队或失败的操作误认为闲鱼已经生效。

## 决策

闲鱼作为平台业务状态的最终来源。XianYuApis 保存消息、商品、订单、评价、账号状态和 Operation/Event 的标准化本地副本与历史账本。断线或重启后通过查询、游标和事件补偿同步差异。

## 结果

- API 可以提供稳定查询、历史记录和完整审计。
- 本地状态需要区分期望状态、观察状态和平台确认状态。
- 所有恢复流程都需要支持增量同步和缺口补偿。
