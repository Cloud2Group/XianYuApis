# ADR-0004：托管账号保留账号主手工操作权

- 状态：Accepted
- 日期：2026-07-28

## 背景

合作账号由平台负责日常运营，但账号主仍可能登录闲鱼查看状态或直接处理事务。要求平台永久独占账号会限制合作方式；允许双方无协调地同时操作又会产生回复、改价和上下架冲突。

## 决策

账号主在托管期间保留手工使用权，平台是默认运营方。账号主的手工操作作为外部状态变化同步进入系统。需要直接操作时，账号进入“人工操作模式”，暂停可能冲突的平台命令；退出人工模式后先同步账号状态，再恢复执行。

## 结果

- Account Runtime 需要观察平台外部发生的账号状态变化。
- 命令执行需要支持账号级或资源级暂停。
- 审计记录需要区分平台操作和账号主手工操作。
